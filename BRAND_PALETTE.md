# CHECK - Professional Brand Palette

## Overview
A refined, sophisticated color system designed for financial clarity and professional aesthetics.
No neon, no glowing effects — just elegant, purposeful design.

---

## Light Theme

### Background Colors
- **Primary Background**: `#fafbfc` - Soft white for main surfaces
- **Secondary Background**: `#ffffff` - Pure white for cards
- **Elevated Surface**: `#ffffff` - Layered elements

### Text Colors
- **Primary Text**: `#1a202c` - Deep charcoal for maximum readability
- **Secondary Text**: `#718096` - Muted slate for supporting content
- **Tertiary Text**: `#a0aec0` - Light slate for hints and labels

### Border Colors
- **Border**: `#e2e8f0` - Soft gray dividers
- **Border Strong**: `#cbd5e0` - Emphasized boundaries

### Brand Accent (C & K)
- **Main Accent**: `#475569` - Refined slate blue
- **Hover State**: `#334155` - Darker slate on interaction
- **Light Variant**: `#64748b` - Softer accent for subtle elements
- **Text on Accent**: `#ffffff` - White text for contrast

### Functional Colors
- **Income**: `#10b981` - Professional emerald green
  - Background: `#d1fae5`
  - Text: `#047857`
  
- **Expense**: `#ef4444` - Clean red (not harsh)
  - Background: `#fee2e2`
  - Text: `#dc2626`

## Shadows (Refined & Professional)

### Light Theme Shadows
- **XS**: `0 1px 2px 0 rgba(0, 0, 0, 0.05)` - Barely-there depth
- **SM**: `0 1px 3px 0 rgba(0, 0, 0, 0.08), 0 1px 2px 0 rgba(0, 0, 0, 0.04)` - Subtle cards
- **MD**: `0 4px 6px -1px rgba(0, 0, 0, 0.08), 0 2px 4px -1px rgba(0, 0, 0, 0.04)` - Elevated elements
- **LG**: `0 10px 15px -3px rgba(0, 0, 0, 0.08), 0 4px 6px -2px rgba(0, 0, 0, 0.04)` - Modals
- **XL**: `0 20px 25px -5px rgba(0, 0, 0, 0.08), 0 10px 10px -5px rgba(0, 0, 0, 0.02)` - Overlays

### Dark Theme Shadows
Deeper and more defined for contrast against dark backgrounds.
- **XS**: `0 1px 2px 0 rgba(0, 0, 0, 0.3)`
- **SM**: `0 1px 3px 0 rgba(0, 0, 0, 0.4), 0 1px 2px 0 rgba(0, 0, 0, 0.3)`
- **MD**: `0 4px 6px -1px rgba(0, 0, 0, 0.4), 0 2px 4px -1px rgba(0, 0, 0, 0.3)`
- **LG**: `0 10px 15px -3px rgba(0, 0, 0, 0.5), 0 4px 6px -2px rgba(0, 0, 0, 0.3)`
- **XL**: `0 20px 25px -5px rgba(0, 0, 0, 0.6), 0 10px 10px -5px rgba(0, 0, 0, 0.3)`

---

## Border Radius (Softened)
- **SM**: `6px` - Small elements
- **MD**: `10px` - Standard cards
- **LG**: `14px` - Large surfaces
- **XL**: `18px` - Modals and overlays

---

## Typography
- **Font Family**: `'Inter', system-ui, sans-serif`
- **Brand Name (CHECK)**: 700 weight, 0.1em letter spacing
- **Tagline**: 400 weight, subtle and secondary
- **UI Text**: Regular weights, high readability

---

## Focus States
**No glowing rings** — Instead:
- Clean `1px` border in brand accent color
- `box-shadow: 0 0 0 1px var(--color-brand-accent)` for subtle outline
- Professional and accessible

---

## Design Principles
✅ **Professional** - Refined, muted tones suitable for finance  
✅ **Accessible** - High contrast, clear hierarchy  
✅ **Calm** - No harsh colors or aggressive shadows  
✅ **Purposeful** - Every color serves a function  
✅ **No Neon** - All accents are muted and sophisticated  
✅ **Elegant Shadows** - Soft depth, not harsh drops
