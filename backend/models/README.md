# Models

This directory will contain Mongoose model schemas for MongoDB collections.

## Example Structure (Future):
- `Transaction.js` - Transaction schema (amount, category, date, etc.)
- `User.js` - User schema (name, email, password, etc.)
- `Category.js` - Category schema (name, type, budget, etc.)

Models define the structure of documents in MongoDB collections and provide methods for data validation and manipulation.
